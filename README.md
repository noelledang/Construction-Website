# NANO CONTRACTING

A responsive renovation and remodeling website for NANO CONTRACTING, built in React + TypeScript with Vite.

## Brand

- Navy and gold visual system
- Slogan: **New house. Same address.**
- Modern minimalist architectural direction
- Mobile, tablet, and desktop layouts

## Current features

- Services section
- About / approach messaging
- Past-project placeholders
- Project inquiry form
- Bottom-screen NANO project assistant
- FAQ path
- Appointment request flow
- Responsive mobile navigation
- Reduced-motion support

## Important

This GitHub project is a reconstructed standalone source version of the NANO CONTRACTING site created in ChatGPT Sites. It is not a byte-for-byte export of the internal Sites runtime.

The current form and appointment flows intentionally do **not** send data to an external service. Submissions remain client-side until an email, CRM, calendar, form provider, or chatbot service is explicitly connected.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Hosting

The existing ChatGPT-hosted NANO CONTRACTING site is separate from this GitHub repository. Pushing changes here does not modify that hosted site automatically.
